# 🧠 Day 5 — Context Power Lab
## ABTalks 60-Day Claude AI Mastery Challenge

## 📌 What I Built
An interactive side-by-side lab that proves — live — how context
transforms a generic AI prompt into a personalized 30-day roadmap.

## 💡 The Big Insight
I ran the same prompt twice.
One returned advice for a ghost.
The other returned a plan for me.
The only difference? 6 lines of context.

## 🔑 Prompt Engineering Law #1
> "The quality of your output is a direct function
>  of the quality of your input context."

## 🛠 How It Works
1. User fills in 6 context fields (situation, skills, goal, time, level, style)
2. Claude API is called with BOTH prompts simultaneously
3. Outputs appear side by side — the difference is immediately obvious
4. User votes on 3 questions → Claude generates a personalized insight

## 📊 What Context Changes
| Without Context | With Context |
|---|---|
| Generic weekly plan | Plan built around YOUR hours/day |
| Random resource list | Resources matched to your level |
| Generic project ideas | Projects aligned with YOUR goal |
| One-size-fits-all | One-size-fits-YOU |
