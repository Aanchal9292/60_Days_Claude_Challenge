Built: A Personal AI Playbook — turning my own job-hunt prompts into a reusable system

I noticed I was retyping the same kind of prompt for every application — tweak a resume bullet here, rewrite a cover letter opener there. So instead of writing prompt #47, I built the system that generates all of them.

What I Built:
✅ A Prompt Builder — assemble custom prompts from labeled blocks (Role, Objective, Context, Constraints, Reasoning Strategy, Output Format, Tone, Quality Checks), each with a plain-language "why this matters" explanation
✅ A Loop Builder — turns any prompt into a self-checking one: Claude drafts, evaluates its own output against criteria I set, revises, and stops only when it meets the bar
✅ 8 ready-made workflows across Resume Tailoring, Cover Letters, Outreach Messages, and LinkedIn Posts — fill in a few blanks, get a tailored prompt, live preview included
✅ Favorite, duplicate, search, and save custom workflows — all stored locally, nothing leaves the browser

Key Insight:
The real productivity bottleneck was never "I don't know what to ask AI." It was rewriting the same structure every time. Once I separated the reusable skeleton (role, constraints, format) from the one-off details (this job, this company), one afternoon of building saved me from typing the same instructions for the next 60 applications.

What's Next:
Stress-testing the Loop Builder on a real cover letter — curious whether a self-critiquing prompt actually catches generic filler better than I do on a first pass.

Building in public means noticing your own repetition before it becomes a habit you never examine.
