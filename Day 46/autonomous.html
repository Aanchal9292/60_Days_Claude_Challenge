🏗️ Architecture Overview
Planner — Creates task plan from user goal
Executor — Produces initial output from plan
Evaluator — Scores output against criteria (0–100)
Critic — Provides structured critique and reasoning
Improver — Refines output based on eval + critique
Memory Manager — Maintains context across rounds
Safety Monitor — Checks for policy violations / bias
Final Reviewer — Produces final output at stop
Stop-check governs flow: Each round, Evaluator → Critic → Improver. Stop fires on Threshold (score ≥ target), Plateau (Δ < 2 for 2 rounds), or Cap (safety max). Final Reviewer then synthesizes the best version.
