Built: Defend Your Experience — an AI that interviews you until your project story holds up

Every portfolio project looks impressive in a bullet point. The real test is whether it survives a technical interviewer asking "why did you do it that way" three times in a row. So I built a tool that does exactly that — to myself, before someone else does.

What I Built:

 ✅ Paste in a project description, and Claude extracts every specific, checkable claim in it — not vague marketing language, actual things you'd have to defend

 ✅ A live adaptive interview: one question at a time, targeting a specific claim, getting harder based on how you answer — no fixed script

 ✅ Honest strong/adequate/weak scoring on every answer, with a note on exactly what detail would make it stronger

 ✅ A Defense Report at the end — claim-by-claim breakdown, overall score, exportable, with session history so I can track if my defense actually improves over time

Key Insight:

 I ran it on my own Autonomous Agent Studio project and got called out for exactly the answer I always give under pressure — the confident-but-vague one. The tool didn't accept "it evaluates quality and stops when it's good enough." It kept asking what "good enough" actually means until I had to say the real number and the real tradeoff. That's the gap between a resume bullet and an interview-ready story.

What's Next:

 Running every project from this challenge through it before I start applying — better to get skeptically interrogated by Claude now than freeze on the real thing.

Building in public means finding out which of your own stories don't hold up yet — while there's still time to fix them.
