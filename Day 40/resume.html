System prompt design

The Claude call is grounded with a single system prompt that plays a narrow role: ATS Resume Auditor. It's instructed to score five fixed categories (keyword match, impact/metrics, formatting, section structure, seniority fit) rather than free-form commentary, because a fixed rubric is what makes scores comparable across runs and easy to render into UI. The prompt forces a strict JSON output schema — no prose outside the JSON — so the frontend never has to guess at parsing free text.

Edge cases are handled explicitly in the prompt: if the pasted text isn't resume-shaped (too short, no work/education signal), the model returns an error field instead of fabricating a score. If no job description is given, it still scores general ATS-readiness but flags that keyword-match scoring is unavailable. The prompt also tells the model to never invent achievements or numbers that aren't in the source resume — only to point out where a metric is missing.

Why this UI

A resume checker isn't a chat product — the user wants a verdict, not a conversation. The layout mirrors an actual scanning instrument: input on the left, a circular gauge and severity-coded flags on the right, so the "scan" metaphor (the literal ATS pattern-matching your resume) is physical, not just a name. Color does the categorizing work: red/amber/teal severity on flags means someone can triage without reading every line.

Extending it

  • Tools: add a web_search tool call so the model can pull real, current ATS keyword norms for a given job title instead of relying on the pasted JD alone.
  • Memory: store prior scans (localStorage or a backend) so a user can track score improvement across resume versions.
  • Multi-step flow: chain a second Claude call that takes the fix list and rewrites the flagged resume bullets directly, turning this from a diagnostic tool into an editing one.
  • File support: this build reads plain text only (no external libraries permitted). A production version would add a PDF/DOCX text-extraction library before this system prompt step.
